# 欧洲亚马逊图片翻译与验收

一个用于 Codex 的图片本地化 Skill：将美国亚马逊链接和本地 Amazon / Wayfair 产品素材，整理为德语、法语套图、A+及带收纳物的三角度白底主图。

它是一套可执行的工作规范，**不是一键翻译软件**。实际抓取、翻译、图像编辑和文件验收由具备相应工具的 Codex 完成；仓库不包含商品原图、账号凭据或私人项目记录。

## 适用场景

- 按EU产品表筛选“未开售”SKU，读取美国站链接并整理素材。
- 将英文宣传文字本地化为自然的德语、法语，并重新排版。
- 补齐漏掉的A+、指定颜色的A+，或修复已有图片中的文字和背景瑕疵。
- 整理左侧、正面、右侧三个角度的带收纳白底图。
- 建立逐SKU的来源记录、验收结果和完成清单。

## 核心规则

| 项目 | 执行标准 |
| --- | --- |
| 原图优先 | 在线核实后匹配本地素材；无须翻译的原文件直接复制，不重新压缩或缩放 |
| 产品保真 | 优先局部替换文字，保留结构、绳数、纹理和配件；不整图重绘、不拉伸 |
| 实物文字 | 磁性字母、书脊和玩具上的文字属于产品细节，不翻译 |
| 翻译排版 | 先理解完整短语，再按德法表达排版；统一字号、行距、对齐和图标关系 |
| 尺寸换算 | inch × 2.54，四舍五入保留一位小数，德法采用小数逗号 |
| 三角度白底 | 全部带收纳物；需制作时2000×2000，完整产品优先、最长边贴边、不镜像冒充视角 |
| 输出尺寸 | 处理后套图目标2000×2000、A+目标1464×600；比例不同按宽等比输出并记录例外 |
| 原图尺寸例外 | 无须翻译的原文件保留原尺寸及留白，优先于处理图尺寸规则 |
| 变体与A+ | 尽量统一图序、文案和版式；保真优先，可保留原场景差异；父体可共用一个颜色的完整A+ |
| 人物标记 | 来源确认是AI且完整出镜时写入 `contains-synthetic-performer` 元数据，不写在画面上 |
| 完成标准 | 文件齐全、双语视觉验收、尺寸与来源验证通过，才标为可用 |

默认排除美国配送承诺、专利/检测认证、客户评价及其他型号推荐等不宜直接迁移的模块。品牌页按用户要求处理。缺失角度的生成必须有适用授权，不能凭空补产品结构。

## 安装

需要 Git，以及支持本地 Skills 的 Codex 环境。将本仓库克隆到个人skills目录；目标文件夹已存在时先检查，不要覆盖已有自定义版本。

Windows PowerShell：

```powershell
git clone https://github.com/meidefanshenzhan/amazon-eu-image-localization.git "$env:USERPROFILE/.codex/skills/amazon-eu-image-localization"
```

macOS / Linux：

```bash
git clone https://github.com/meidefanshenzhan/amazon-eu-image-localization.git ~/.codex/skills/amazon-eu-image-localization
```

若自定义了 `CODEX_HOME`，请安装到其 `skills/amazon-eu-image-localization` 子目录。Skill 本身不包含图片处理运行时；执行时需要文件访问、页面读取，以及适用的表格、图像编辑和元数据工具。没有工具或无法核实来源时应报告缺项，不声称完成。

## 使用

在 Codex 中提供工作目录和素材范围，并明确调用：

```text
请使用 $amazon-eu-image-localization。

工作目录：<你的工作目录>
产品表：AMZ EU产品总表 待.xlsx
工作表：利润明细
筛选：G列为“未开售”
US链接：J列
本地素材：产品图片视频

请准备德语、法语套图和A+，每个子体补齐三张带收纳白底图。
优先本地原图，完成逐图验收后更新当前进度说明和可用清单。
```

也支持单独补图：

```text
请使用 $amazon-eu-image-localization，重新抓取指定US链接中的4张白色款产品A+。
排除品牌页，保留实物磁性字母，制作德法版本并备份替换旧图。
US链接：<商品链接>
本地素材：<素材目录>
```

完整任务提示词见 [整合版启动提示词](references/starter-prompt.md)。新项目须另行确认人物来源、生成授权及特殊尺寸依据，不能沿用其他项目的事实。

```text
欧洲上架图片/
├── 003/
│   └── 003B/
│       ├── 白底主图/

│       │   ├── 白底主图-正面角度.png
│       │   └── 白底主图-右侧角度.png
│       ├── 003B-德语/
│       │   ├── 套图(1).png
│       │   └── A+(1).png
│       └── 003B-法语/
│           ├── 套图(1).png
│           └── A+(1).png
├── 当前进度说明.txt
├── 已完成可用清单.md
```

保留真实文件格式，不强制全部转JPG。父体共用A+须标明引用位置；预览、备份及失败候选不进入正式交付目录。
