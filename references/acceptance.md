## 来源记录最少字段

SKU、父体、类别、序号、语言、源路径/URL、源ASIN及颜色、原尺寸、输出路径与尺寸、处理方式、文字区域、尺寸换算表、实物文字保护、AI人物标记、原图匹配依据、源/输出SHA256、视觉验收结果、尚存缺项。

处理方式区分：原文件复制 / 仅元数据 / 文字替换 / 等比构图 / 获准生成角度。不得一律写成“原图处理”。

## 技术检查

1. 解码每个实际交付文件，检查尺寸、模式、扩展名和重复编号。
2. 原样复制校验源输出SHA256一致；仅元数据操作验证像素一致；文字替换在缩放前比较编辑区域外像素。
3. 保存后再验证，不仅检查内存中的图片。JPEG有压缩差异时如实报告容差或选定区域检查，不能宣称逐像素一致。PNG保真导出可做精确验证。
4. 逐项复算尺寸，包括内径、小盒、抽屉深度、总高；不能只检查总宽。尺寸图用原图并排检查文字位置与箭头。
5. 验证人物标签可读；确认没有因重新导出丢失标记。
6. 统计独立文件与共享/新版副本，文件数量不代替内容完整性。旧报告在换图后更新，哈希不能仍指向旧版。

## 视觉检查

- 整图：配色、标题层级、文字框长度、同排标签大小、图标和文本是否成组；不能仅缩略图过一遍。
- 原尺寸局部：残余英文/描边、黑洞、涂抹、接缝、双重覆盖、模糊数字、错行与断字。逐张看尺寸图和复杂背景文字区。
- 产品：逐张与对应原图对照绳条数量、门板/把手/轮子/盒子数量、左右结构、材质、磁性字母和玩偶等。典型回归：019的5根绳不可变4根。
- 三角度白底：是否带收纳物、角度真实且非镜像、完整未裁断、颜色/色温一致、缩放后是否确实清楚。原图本身分辨率有限要说明，不凭2000像素画布宣称细节高清。
- 双语：自然的完整短语、重音/变音字母正确、数字与单位正确。不要把不同功能因过度压缩文案而混淆。
- 共享A+：是同父体同产品结构；多色展示不能当成无关型号推荐误删。反之，不得把竞品/其他型号推广当作本SKU功能图。

## 常见失败与处置

| 发现 | 必须采取的动作 |
| --- | --- |
| “Magnetic White Board”变成重复磁性字母或带重音字母 | 从原图恢复整块实物区域，翻译只保留外部说明 |
| 文本小但背景框很长、文字大小忽大忽小 | 以完整短语重排，统一层级，重做适配框 |
| 尺寸图有黑洞/旧数字残留 | 回原图重新做精确文字清除，禁止在错误输出上继续叠加 |
| 页面4张A+仅交付2张 | 重查完整模块/轮播和颜色，补齐并重新编号验收 |
| 无字本地原图被缩放重压 | 恢复原文件复制，更新尺寸例外及哈希 |
| 缺角度被空柜或镜像替代 | 判为未完成，找带收纳对应角度，按授权补制 |

每轮优先完成最接近通过验收的SKU，但不能因此省略其余缺项记录。对新增反馈定位同类图片并排查，不只修用户举例那张。
